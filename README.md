# Desafio da Linha Única

Jogo One Touch em HTML, CSS e JavaScript puros. Abra `index.html` ou publique no GitHub Pages.

## Estrutura
- `index.html` — telas (início, partida, resultado, ranking)
- `css/style.css` — tema escuro neon
- `js/config.js` — tempo, erros, dificuldade e pontuação
- `js/utils.js` — funções auxiliares
- `js/graph.js` — validação euleriana e geometria
- `js/generator.js` — geração das figuras
- `js/score.js` — fórmula de pontuação
- `js/ranking.js` — ranking em localStorage
- `js/ui.js` — troca de telas e avisos
- `js/game.js` — partida, cronômetro e fases
- `js/input.js` — mouse e toque
- `js/main.js` — botões

A ordem dos `<script>` no `index.html` deve ser mantida.
